# FluxXeno

DistributedFluxXeno enables RealtimeFluxXeno processing and analytics through a scalable XenoPlatform, leveraging XenoEngine for adaptive auto-scaling and load balancing.

FluxXeno is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/irenascent/FluxXeno.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

FluxXeno is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
